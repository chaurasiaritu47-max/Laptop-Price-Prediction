# Tilte: Laptop Price Prediction
This project focuses on predicting laptop prices using Machine Learning techniques and an interactive web application built with Streamlit. The dataset was collected from Flipkart and included features such as brand, processor type, RAM size, storage capacity, screen size, operating system, processor generation, and reviews. Data preprocessing techniques like handling missing values, encoding categorical variables, and feature transformation were applied using Scikit-learn pipelines and column transformers to prepare the data for model training.

The project also includes data visualization and user-friendly insights using libraries such as Matplotlib, Seaborn, and Plotly. A machine learning model was trained to predict laptop prices based on user inputs, and the application provides an interactive interface where users can explore predictions and laptop recommendations within a selected price range. The project helped in gaining practical experience in data preprocessing, machine learning model building, visualization, and web app development using Python.Live app link: https://laptop-price-prediction-gebhta5yen9uv5pzxcv7az.streamlit.app/
